# 2. OPENING / POWER-UP ANIMATION

When the website is initially opened:

1. Start with a completely black screen.
2. Keep the screen dark for approximately 1 second.
3. Suddenly create a powerful lightning strike across the screen.

6. Immediately after the lightning strike, smoothly reveal the website.

The animation should feel like:

**an electrical system being powered ON.**

Do not keep the user waiting for a long intro.

The animation should only run when the website is initially loaded.
